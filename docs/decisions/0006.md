# ADR-0006: Differential expression method
Date: 2026-05-18
Status: Proposed — awaiting Armin sign-off

## Context

This is the single most consequential statistical decision in the
pipeline. The headline result every dossier reports is a per-cell-type
PD-vs-control differential expression effect size and significance.
The chosen method determines whether that result is calibrated (false
positive rate matches the nominal alpha) or wildly inflated (false
positive rate orders of magnitude above nominal). The two regimes look
identical in a volcano plot.

The single-cell DE literature has been clear since at least 2021 that
running per-cell statistical tests (e.g., Wilcoxon, MAST) and reporting
the p-values as subject-level inference is *wrong*: those tests treat
each cell as an independent observation, which it is not — cells from
the same donor share donor-level state. The published demonstration
(Squair et al. 2021, Murphy & Skene 2022) is that this inflates Type I
error by one to three orders of magnitude. Pseudobulk DE — aggregate
counts to one row per donor × cell type, then run a bulk DE method —
restores calibrated inference.

This repo's primary results must be defensible to a hostile reviewer.
Pseudobulk DE is the only path to that.

## Options considered

### A. Pseudobulk + pyDESeq2
Sum raw counts within each (donor × cell type) cell. Run pyDESeq2 with
donor as the unit and condition (PD vs control) as the test variable.
Include age, sex, and PMI as covariates (per ADR-0001's consequences).
- Pros: calibrated subject-level inference; well-tested; effect sizes
  and confidence intervals are interpretable.
- Cons: needs sufficient donors per cell type to estimate dispersion;
  for cell types with very few cells in some donors, the donor × cell-type
  sample drops out and statistical power suffers.

### B. Pseudobulk + edgeR / limma-voom
Same aggregation, different bulk DE method.
- Pros: equally calibrated; well-tested.
- Cons: R-based; would force this Python-native pipeline to call out to
  R or to use an unofficial Python port; complicates packaging and CI.

### C. Per-cell Wilcoxon
What scanpy's `sc.tl.rank_genes_groups` does by default. Treats each
cell as an independent observation.
- Pros: simple; fast.
- Cons: **Type I error inflated by 10-1000x in disease cohort settings.**
  Not appropriate as a primary result. Useful only as a secondary check
  on the *direction* of effect inside a single donor.

### D. MAST
Hurdle model for the bimodal expression of single-cell data, with
random-effects support.
- Pros: handles zero inflation; supports donor random effects.
- Cons: requires careful specification; in practice donor random effects
  often fail to fit at the sample sizes we have; slower than pseudobulk
  + DESeq2; mixed reception in the benchmarking literature.

## Criteria for choosing

1. **Type I error calibration in the cohort regime.** The chosen method's
   nominal alpha must reflect actual false positive rate.
2. **Python-native.** ADR-0003 commits the stack to scanpy; bringing in
   R fragments the dependency story and complicates the CI runner.
3. **Effect-size interpretability.** log2 fold change at the donor level
   is what dossiers need to display.
4. **Power at our sample size.** At ~11 donors, no method will produce
   abundant per-cell-type significant hits. The chosen method should
   degrade gracefully (wider CIs) rather than spuriously confident.

## Decision

**Option A: pseudobulk aggregation + pyDESeq2.**

Specifics:
- Aggregation: sum raw counts within each (donor, cell type) pair, using
  the cell-type labels from ADR-0005's ambiguity-filtered annotation.
- Pseudobulk samples are dropped if a donor × cell-type cell has fewer
  than 10 nuclei contributing (configurable; default 10).
- pyDESeq2 is run **per cell type**. PD vs control is the design variable;
  age, sex, and PMI are covariates.
- Output per cell type is a table with: gene, log2FC, lfcSE, stat,
  pvalue, padj (BH within cell type — see ADR-0007).
- Per-cell Wilcoxon (Option C) is **also run** but is reported only as a
  secondary check on direction of effect inside a single donor. It does
  not appear as a primary result in any dossier panel.

## Consequences

- For cell types with very few cells (rare microglia subpopulations, or
  cell types lost to QC in some donors), pseudobulk DE will be
  underpowered. The dossier reports this as "underpowered for this cell
  type" rather than imputing a result.
- The README must explicitly call out that the primary DE is pseudobulk,
  citing Squair et al. 2021. This is portfolio-defensibility material:
  a hiring panel reviewing this repo will check for this specifically.
- Single-cell Wilcoxon will appear in some intermediate figures (e.g., a
  per-donor breakdown plot) but with clear labeling that it is a
  direction-of-effect check, not a calibrated test.
- pyDESeq2 adds a heavier dependency than scanpy alone; this is
  acceptable given the importance of the result.
