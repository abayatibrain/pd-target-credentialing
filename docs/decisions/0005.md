# ADR-0005: Cell-type annotation strategy
Date: 2026-05-18
Status: Accepted (Armin 2026-05-18)

## Context

Every downstream result in this repo is cell-type-conditioned. Pseudobulk
DE (ADR-0006) requires a cell-type label per nucleus; the dossier's
"expression by cell type" panel requires labels; the cross-cohort
validation against Kamath (ADR-0001) requires labels that are comparable
between datasets. The annotation method must produce labels that are
**auditable** — a reviewer should be able to read why each cluster was
called "DA neuron" rather than "GABAergic neuron" without re-running the
analysis.

The substantia nigra is fortunate compared with, say, cortex: its
canonical cell types have well-characterized marker panels, and the
biology has been described for decades. This ADR commits to an explicit
marker panel, with the Kamath atlas serving as a labeled reference for
cross-validating the most important call — the DA-neuron call.

## Options considered

### A. Marker-based scoring (manual panel)
Define a marker panel per cell type. Score each cluster against the panel.
Assign the label with the highest score; flag clusters whose top two
scores are within a small margin for manual review.
- Pros: every label has a documented reason; markers are citable to the
  literature; failures are debuggable.
- Cons: marker choice is a subjective surface; novel cell states may not
  fit any panel and get mis-labeled.

### B. Reference-based label transfer (Azimuth-style)
Project nuclei into a reference atlas's embedding and transfer labels.
- Pros: leverages curated reference; consistent across datasets that use
  the same reference.
- Cons: the reference's labels become load-bearing; debugging a wrong
  label means debugging the reference, which is out of scope; for the
  substantia nigra specifically, no single canonical reference atlas has
  the consensus status that, e.g., Tabula Sapiens has for general tissues.

### C. Hybrid — marker-based primary, reference cross-check
Use marker-based scoring as the primary label assignment. Independently,
project DA-labeled nuclei into the Kamath embedding and check that they
co-locate with Kamath's DA labels. Any disagreement is logged and reviewed.
- Pros: combines auditability of A with the cross-validation strength of
  B; gives the README a defensible figure (DA neurons here line up with
  DA neurons there).
- Cons: more code; cross-validation introduces its own failure modes.

## Criteria for choosing

1. **Auditability of the DA-neuron call.** The DA-neuron call is the most
   biologically load-bearing label this pipeline makes. It must be
   defensible from canonical markers (TH, SLC6A3, DDC) and corroborated
   externally.
2. **Reproducibility.** Label assignment for a given input + marker panel
   must be deterministic.
3. **Compatibility with cross-cohort validation (ADR-0001).** The Kamath
   atlas is the cross-cohort reference; the annotation strategy should
   make use of it.

## Decision

**Option C: hybrid.** Marker-based scoring with an explicit, citable
panel, followed by an independent cross-check of DA-neuron labels against
Kamath 2022.

### Canonical marker panel (initial draft — subject to Armin review)

| Cell type | Markers (approved HGNC symbols) | Notes |
|---|---|---|
| Dopaminergic neuron | TH, SLC6A3 (DAT), DDC, NR4A2 (Nurr1), KCNJ6 (Girk2) | KCNJ6 enriches in vulnerable A9 subtype |
| GABAergic neuron | GAD1, GAD2, SLC32A1 (VGAT) | |
| Glutamatergic neuron | SLC17A7 (VGLUT1), SLC17A6 (VGLUT2) | |
| Astrocyte | AQP4, GFAP, SLC1A2 (EAAT2) | |
| Microglia | CSF1R, P2RY12, TMEM119, CX3CR1 | |
| Oligodendrocyte | PLP1, MOG, MBP | |
| OPC | PDGFRA, CSPG4 | |
| Endothelial | CLDN5, PECAM1 | |
| Pericyte | PDGFRB, RGS5 | |

DA-subtype calls (SOX6-positive vulnerable, CALB1-positive less-vulnerable)
are **in scope for v1.0.0** (per Armin sign-off 2026-05-18, Q5.3). They are
not assigned by the top-level marker scoring above — instead, nuclei
labeled "DA neuron" are sub-classified in a separate step against the
Kamath reference atlas. The dossier reports the subtype call only when
the Kamath cross-check succeeds.

## Consequences

- The marker panel is a load-bearing artifact and lives in version-controlled
  code (`src/pd_target_credentialing/annotate/markers.py`), not in a free-text
  document.
- Any clusters where the top two cell-type scores are within a margin
  (default 0.15 of the max score) get flagged "ambiguous" and excluded from
  cell-type-conditioned DE rather than silently mis-labeled.
- DA-subtype labels appear in the dossier only when the Kamath cross-check
  succeeds. If the cross-check disagrees substantially, the dossier reports
  "DA neurons (subtype not resolved)" and the disagreement is logged.
